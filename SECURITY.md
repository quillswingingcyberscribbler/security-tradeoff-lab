# Security and sensitive data

This project contains decision-support workbooks and review scripts. The spreadsheets do not enforce runtime permissions, validate organizational evidence or replace an operational control.

Report ordinary formula and documentation defects using the issue template with a synthetic reproduction. Do not attach a completed organizational assessment to a public issue.

For a vulnerability or accidental disclosure involving sensitive information, use GitHub private vulnerability reporting if the repository owner has enabled it. Otherwise use a verified private contact channel listed on the owner's GitHub profile and ask how to submit the details. No dedicated mailbox or response-time commitment is established by this package.

Keep working assessments under `local/` or another access-controlled location outside the public repository. The ignore rules help avoid accidental commits; they are not a confidentiality control.
