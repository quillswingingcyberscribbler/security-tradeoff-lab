# Licensing decision

The supplied workbook files do not contain an explicit reuse license grant. Preparing this repository does not silently grant one. The source files retain their existing rights.

A concrete MIT license text is provided in [LICENSES/MIT.proposed.txt](LICENSES/MIT.proposed.txt) for the author's review. It is a proposal, not the operative license. Before an open-source release, confirm the rights and intended scope, then copy the approved text to a root `LICENSE` file and update this page and the citation metadata.

A practical allocation consistent with the companion GL-Agent project would be MIT for workbook/code and CC BY 4.0 for explanatory documentation, figures and examples. That allocation has not been applied automatically to this project. A single MIT license covering all original material is another simpler choice if that is the author's preference.

For the meaning and effect of a repository license, see [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) and the [MIT text](https://choosealicense.com/licenses/mit/). Cited standards, research and third-party content retain their respective rights.
